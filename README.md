# Network Infrastructure Analyzer (OSINT Tool)

Este proyecto es una herramienta automatizada desarrollada en Python para la recolección de ciberinteligencia y el análisis de infraestructura web mediante fuentes abiertas (OSINT). Está diseñada para apoyar tareas de análisis forense digital, detección de activos maliciosos expuestos y mitigación de fraude electrónico o distribución no autorizada de contenido (Brand Protection / Antipiratería).

## 🚀 Características Principales

* **Geolocalización de Activos:** Identificación geográfica automatizada de direcciones IP y dominios sospechosos.
* **Mapeo de ASN:** Clasificación de redes para discernir entre proveedores de internet residencial (ISP) y centros de datos (Datacenters/Hosting), vector clave para la detección de anomalías y uso de proxies/VPNs.
* **Auditoría de Seguridad de Red:** Análisis pasivo de servidores para evaluar exposición de infraestructuras críticas.

## 🛠️ Tecnologías y Librerías Utilizadas

* **Python 3** como lenguaje principal de automatización.
* **Requests** para la gestión e integración de APIs de ciberinteligencia.
* **JSON** para el parseo y estructuración analítica de datos de red.
